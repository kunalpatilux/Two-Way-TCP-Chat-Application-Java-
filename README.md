A simple two-way communication chat application built using Java Sockets (TCP) and Swing GUI.
This project demonstrates client–server communication, real-time message exchange, and GUI-based chat windows.

🚀 Features

✔️ TCP-based two-way communication

✔️ Separate Server and Client programs

✔️ Java Socket and ServerSocket implementation

✔️ Real-time message sending & receiving

✔️ Swing GUI for chat window

✔️ Supports multiple clients (optional extension)

🛠️ Technologies Used

Java (JDK 8+)

Java Networking (Socket / ServerSocket)

Java Swing (GUI)
